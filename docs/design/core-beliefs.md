# Core beliefs

- Verification is separate from generation; an executor cannot verify itself.
- Cheap incorrect work is still incorrect.
- The economic metric is cost per verified successful task, not cheap attempts.
- Authority, scope, budgets, and required checks are explicit contracts.
- Evidence survives the agent and is append-only.
- Lifecycle transitions are explicit; execution success is not verification success.
- Prefer deterministic mechanisms where possible; they outrank model self-report.
- Provider-specific logic stays at system edges.
- Failure is data and must be retained for evaluation.
- Claims require provenance in recorded evidence.
- Complexity must earn admission through a demonstrated requirement or ADR.
