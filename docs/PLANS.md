# Execution plans

Create or update an active execution plan before non-trivial, multi-step work:
changes spanning packages, new lifecycle behavior, architectural boundaries,
experiments, migrations, or work with material reliability/security impact. Plans
state scope, assumptions, ordered work, verification, risks, and explicit non-goals.

Small isolated fixes may use the issue or pull-request description when it provides
the same clarity. Move completed plans to `docs/exec-plans/completed/` only after
their required verification is recorded.
